# L298N DC Motor Driver Schematic

## Overview
This project contains a complete schematic for a DC motor control system using the L298N dual H-bridge motor driver IC. The design includes a regulated power supply, flyback diode protection, and screw terminal motor outputs for safe and reliable motor operation.

## Features
- Dual DC motor control (Forward / Reverse)
- L298N dual H-bridge motor driver
- Regulated logic power supply
- Flyback diodes for back EMF protection
- Screw terminal motor connections
- Suitable for robotics and automation projects

## Schematic Blocks
- **Power Supply**  
  Provides regulated voltage for logic and control circuitry.

- **Flyback Diode Network**  
  Protects the driver from inductive voltage spikes generated by motors.

- **L298N Motor Driver**  
  Controls direction and speed of two DC motors using digital control inputs.

- **Motor Output Terminals**  
  Screw terminals for secure DC motor connections.

## Pin Description (L298N)
- IN1–IN4 : Direction control inputs  
- ENA / ENB : Motor enable pins (PWM speed control)  
- OUT1–OUT4 : Motor output pins  
- VS : Motor supply voltage  
- VSS : Logic supply voltage  
- GND : Ground
